# Item preview anchor (#48)

The touch tooltip hook replaced the native item rectangle with a point on the opposite side panel. This made a bottom-right item appear described at the top left. The default now preserves the native rectangle, allowing the original tooltip engine to place above/below the item and perform its existing screen-edge clamping. The previous docking remains available only as an explicit `DM_TEST_TIPDOCK=1` control for native comparisons.

The test includes the actual `dm_cursor.c` callback with an authored widget tree. Before the change, all four corner rectangles were overwritten (4 failures); afterwards all four are preserved, with other registers unchanged. The forced legacy control still reproduces docking.
