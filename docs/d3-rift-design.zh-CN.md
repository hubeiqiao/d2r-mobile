# D3大秘境：随机、词缀与D2适配研究

2026-10-13。证据来自暴雪历史正式补丁与PTR；标注版本，不把旧版无限层/试炼石规则当成当前规则，也不声称拿到了D3内部概率表。下文「提案」是本项目设计，不是D3技术事实。#28仍是试验草稿，完整机制未实现。

|Boss与长线目标|[2.1.2](https://news.blizzard.com/en-us/article/17561388/patch-2-1-2-now-live)修正不公平的Boss伤害/控制重叠；[2.1.0](https://news.blizzard.com/en-us/article/15487814/patch-2-1-0-now-live)将宝石升级机会与完成层数/宝石等级关联|困难来自可应对机制，奖励要有可积累目标；不照搬过时钥石升级流程|

核心设计推论：构筑×地图空间×怪群行为×精英词缀×路线/临时优势共同改变每场决策。可控随机应制造不同可处理的局面，不能每场只随机一组乘数，也不该靠完全随机惩罚制造重开刷图。上述补丁证明多个维度被调过，不公开完整概率/排斥算法。精英具体抽签权重、词缀槽数、塔生成完整规则未从这些来源证实，暂不写成确定事实。

## 当前项目的差距

`dm_rift.c`原来固定野外→迷宫、固定普通密度3倍/250分；#28加入密度/精英比例、每图扰动、随机路线编排和观察统计，但怪物品种仍按原图原生池。源码的「首版不含」注释明确冠军/金怪词缀数量及抗性/免疫权重尚未实现。不能把原生存在的随机金怪当成已经做好大秘境词缀系统。

100层怪等级早已封顶，生命有8388607上限；同时角色奖励继续变强。调曲线必须先修#23，测清怪/Boss阶段和封顶比例，不能仅增加生命配置。HUD100→103属于独立显示Bug，#29/#30修复不改变上限或奖励。

## 后续落地顺序与验收

1. **怪群库**：先定义近战群、远程压制、支援/召唤、耐久精英四种角色模板（设计类别，不是已核验类号）。本地资源验证每个候选的动画/AI/房间/任务依赖；建立地图兼容白名单。建议每组一种主群＋至多一种辅助群，并留入口安全区。原生验证生成分布、AI、任务事件、尸体/退出清理和封顶，禁止上传游戏派生表。
2. **词缀白名单与风险预算**：先复用已验证的D2原生金怪修饰生成入口，不直接改裸flags冒充词缀。分类为移动压力、地面危险、爆发/投射、控制、增援、防御。每包至多一个硬控类；硬控＋快速高爆发、狭窄区域＋封路、免疫组合等作为候选排斥项，需要全职业验证。首期只增加已核验、安全可识别组合；禁止无预警致死。预算/排斥是提案，未加到运行代码。
3. **可读性**：精英名称显示实际修饰；危险预警先于伤害，有可移动安全区。iPad遮挡、帧时间与控制响应是验收条件。不能把D3美术/能力硬搬进D2，原生无预警能力不得凭假测试宣称安全。
4. **推进与重复收益**：把速刷、推进、封顶挑战三个目标区分。100封顶保持诚实；最高层、最佳时间、无死亡等记录可以给挑战目标，不私自开放103。优先复用已有碎片与兑换用途，提出部位/类别目标兑换和有限周期性奖励，评估产出/小时和物品通胀；不直接许诺满变量或增加技能点无限成长。
5. **哥布林**：作为明确标注的D2自定义追逐事件，不能称为D3大秘境标准规则。建议可选、每场最多一次、有限逃跑时限、死亡或逃跑奖励只结算一次，退出/暂停/新场清理，不能阻止守护者或开新场。生物/AI、词缀排斥、战利品和存档一致性尚未核验，未实现；是否进入竞技推进模式需作者决定。

## 可执行验证

固定两套构筑（开荒/成型），先#23，再70/80/90/100多场。报告选中地图/群体/词缀、权重版本、随机结果、配置值、原生生成量、客户端观察量、精英遭遇与跳过、各类进度、移动/清怪/Boss耗时、死亡原因、有效生命封顶及产出/小时。常规方案和稀有方案分开统计，不能用一个角色少量样本推整体平衡。

每档同时跑旧规则和新规则；同配置重进不重抽，暂停不走游戏时间，完成与放弃恢复原值。检查地图耗尽不丢旧场奖励、Boss奖励可拾取并保存。iPad群怪测p95帧时间/温控/输入；性能不达标降低密度或否决方案。随机分布测试只能证明策略抽签，不能证明原生实生成或趣味。
